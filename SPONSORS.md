# Manual Sponsors List

One entry per line, starting with `- `. These names appear in the README
Supporters section under "Sponsors:" header.

Edit this file to add or remove supporters from non-GitHub-Sponsors sources
(Ko-fi, Buy Me a Coffee, one-time donations). GitHub Sponsors entries are
fetched automatically by `scripts/sync_sponsors.py`. Ko-fi + BMC donations
arrive via the donation-webhooks Cloudflare worker.
